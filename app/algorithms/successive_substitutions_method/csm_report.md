# Метод последовательных уступок (МПУ)
## Исходные данные
Количество переменных: **2**

Количество целевых функций: **2**

Количество ограничений: **5**

Целевые функции:
 - Z1 = 1x1 -3x2 → max
 - Z2 = 2x1 -2x2 → min

Уступки:
 - δ1 = 2.0
## Последовательная оптимизация
## Шаг 1 — оптимизация Z1 (max)
На первом шаге оптимизируем главную целевую функцию на исходной системе ограничений.

| Переменная | Значение |
| --- | --- |
| x1 | 0.0 |
| x2 | 1.0 |
| Z1 | -3.0 |

Добавлено ограничение-уступка: **Z1 ≥ -3.0000 − 2.0 = -5.0**
## Шаг 2 — оптимизация Z2 (min)
На шаге 2 оптимизируем Z2 с учётом уступок по предыдущим функции.

| Переменная | Значение |
| --- | --- |
| x1 | 0.0 |
| x2 | 1.666667 |
| Z2 | -3.333333 |

## Итоговые значения
| Показатель | Значение |
| --- | --- |
| x1 | 0.0 |
| x2 | 1.6667 |
