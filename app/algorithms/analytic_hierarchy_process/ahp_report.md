# Метод анализа иерархий (AHP)
## Критерии и альтернативы
Критерии:
- Время реакции техподдержки (часы)
- Глубина хранения логов (дней)
- Наличие русскоязычной документации (балл 1-10)
- Наличие сертификатов безопасности (кол-во)
- Поддержка облачного развёртывания (балл 1-10)
- Производительность (10^5 событий/сек)
- Простота создания пользовательских правил (балл 1-10)
- Скорость обнаружения угроз (мин)
- Скорость развёртывания (дней)
- Соответствие требованиям ФСТЭК/ФСБ (балл 1-10)
- Стоимость лицензии (млн.руб/год)
- Точность обнаружения (% ложных срабатываний)
- Удобство интерфейса (балл 1-10)

## Оценка согласованности
При использовании метода анализа иерархий важно проверить согласованность экспертных оценок.
**Индекс согласованности (CI)** показывает степень отклонения матрицы парных сравнений от идеально согласованной матрицы.
**Коэффициент согласованности (CR)** — это отношение индекса согласованности к случайному индексу. Он показывает, насколько полученные оценки согласованы по сравнению со случайной матрицей.

| Показатель | Значение |
| --- | --- |
| Индекс согласованности (CI) | 0.055393 |
| Коэффициент согласованности (CR) | 0.035508 |


Интерпретация коэффициента согласованности:

| CR | Интерпретация |
| --- | --- |
|  &lt; 0.1 | Хорошая согласованность |
| [0.1; 0.2] | Допустимая согласованность |
|  &gt; 0.2 | Матрица плохо согласована |


Полученное значение **CR = 0.0355**, что меньше 0.1. Следовательно, матрица парных сравнений имеет **хорошую согласованность**, и результаты анализа можно считать надежными.
